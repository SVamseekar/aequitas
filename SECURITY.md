# Security

Please report vulnerabilities privately. Do not open a public GitHub issue for an unpatched (0-day) report.

**Email:** [martisoura@gmail.com](mailto:martisoura@gmail.com)

Include:

- Affected surface (API route, auth, warehouse query, frontend)
- Steps to reproduce
- Impact (data exposure, session theft, injection)

You should receive an acknowledgement within a few days. Please give a reasonable window to patch before any public disclosure.

This project is local-first analytics plus a static marketing site. Warehouse files and `.env` secrets must stay off git; see [CONTRIBUTING.md](CONTRIBUTING.md).
